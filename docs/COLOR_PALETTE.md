# VISION AI — Color Palette

All colors are defined centrally in `lib/core/theme/vision_colors.dart` and exposed through `VisionThemeExtension` (`context.visionColors`).

## Dark Theme — Midnight Violet

| Semantic Token | Hex | Usage |
|---|---|---|
| `background` | `#101016` | Primary scaffold backdrop |
| `secondaryBackground` | `#15151E` | Secondary atmospheric layer / code block backdrop |
| `surface` | `#191823` | Standard cards, dialogs, sheets |
| `elevatedSurface` | `#22212E` | Inputs, floating bars, raised surfaces |
| `primary` | `#A78BFA` | Primary interactive accent, active states, orb core |
| `primaryContainer` | `#35284E` | Selected chips, highlighted icon badges |
| `secondary` | `#65E6C1` | Secondary accent, listening/active telemetry |
| `tertiary` | `#F0A6C8` | Soft rose-pink gradient accent |
| `textPrimary` | `#F5F1FA` | Primary headings & body copy |
| `textSecondary` | `#B6B0C2` | Subtitles, timestamps, metadata |
| `border` / `outline` | `#302D3C` | Card & input strokes |
| `success` | `#65D6A5` | Success indicators & connected status |
| `warning` | `#F4BD70` | Caution notices & battery warnings |
| `error` | `#FF858D` | Error states & destructive actions |
